# Shoka local source fonts

These source fonts are used only during `hexo generate`. They are subset into
WOFF2 files by `scripts/generaters/font-subset.js`; the full TTF files are not
published to the site.

Source: `google/fonts` commit
`038b637da7b3fd956a4ed93ffc607c3d5e4ce172`.

- `Mulish-Variable.ttf`: `ofl/mulish/Mulish[wght].ttf`
- `Mulish-Italic-Variable.ttf`: `ofl/mulish/Mulish-Italic[wght].ttf`
- `FrederickaTheGreat-Regular.ttf`: `ofl/frederickathegreat/FrederickatheGreat-Regular.ttf`
- `NotoSerifJP-Variable.ttf`: `ofl/notoserifjp/NotoSerifJP[wght].ttf`
- `NotoSerifSC-Variable.ttf`: `ofl/notoserifsc/NotoSerifSC[wght].ttf`
- `Inconsolata-Variable.ttf`: `ofl/inconsolata/Inconsolata[wdth,wght].ttf`

The corresponding SIL Open Font License files are stored in `licenses/`.
